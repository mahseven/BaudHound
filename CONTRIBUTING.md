# Contributing

Bug reports, patches and board reports are welcome: open an issue or a pull request on
https://github.com/info-mah7/BaudHound.

## Licence of contributions

A patch you send is licensed under the MIT licence in LICENSE, unless you state otherwise in
writing when you send it.

Code taken from elsewhere must carry a compatible licence, and its notice goes in README.md under
the licences of the libraries the firmware builds with.
